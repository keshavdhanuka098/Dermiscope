# 🩺 Dermiscope – AI Skin Disease Detection

Dermiscope is an AI-powered web application designed to detect and analyze skin diseases using deep learning and computer vision. It helps users upload skin images and receive intelligent predictions with a modern, responsive interface.

---

## 🚀 Live Preview

🔗 Live Website: https://dermiscope.netlify.app/

---

## ✨ Features

✅ AI-powered skin disease prediction  
✅ Upload skin images for instant analysis  
✅ Fast and responsive user interface  
✅ Deep learning-based classification  
✅ Clean and modern design  
✅ User-friendly experience  
✅ Real-time prediction display

## 📸 How It Works

1. Upload an image of the skin condition  
2. AI processes the uploaded image  
3. Deep learning model analyzes patterns  
4. Prediction result is displayed instantly  

---

## 🎯 Project Objective

The goal of Dermiscope is to provide an accessible and intelligent solution for preliminary skin disease analysis using artificial intelligence, making dermatological insights faster and more convenient.
